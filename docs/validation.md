## 恢复验证

运行 `uv run --frozen python -m scripts.verify`：

1. 每批 2 条输入，第一批提交后注入执行中断。
2. 数据库保留 1 台有效设备与对应水位。
3. 重新运行后补齐 2 台设备，最终共 3 台。
4. 全量重放新增 0 台，3 台均识别为未变更。

此处验证的是模拟异常边界以及已持久化状态的恢复；不是实际断电测试。自动化测试另外覆盖未提交批次回滚、过期 Worker 租约接管和并发互斥。
